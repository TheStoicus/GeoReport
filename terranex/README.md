# TerraNex — начальная настольная оболочка

TerraNex — развиваемая на C++20 и Qt 6 настольная геологическая система. Этот каталог представляет **отдельную начальную Qt-программу** и не заменяет рабочее приложение GeoReport.

## Требования

- CMake 3.20 или новее
- C++20-компилятор
- Qt 6.6 с модулем Widgets
- CLion или другая среда с поддержкой CMake

## Сборка на macOS

Если Qt установлен в `/Users/al.deshkovets/Qt`, укажите путь к конкретной версии Qt в `CMAKE_PREFIX_PATH`. Путь зависит от фактически установленной версии и набора Qt.

Из корня репозитория:

```bash
cmake -S terranex -B build-terranex \
  -DCMAKE_PREFIX_PATH="/Users/al.deshkovets/Qt/<версия>/macos"
cmake --build build-terranex
```

Если используете CLion, откройте каталог репозитория или непосредственно каталог `terranex`, затем настройте CMake-профиль с тем же `CMAKE_PREFIX_PATH`.

## Текущее состояние

Сейчас реализованы:
- отдельная точка входа Qt;
- главное окно и меню;
- выбор папки проекта;
- базовая заготовка списка будущих модулей.

Пока **не реализованы** загрузка геологических данных, БД PostgreSQL/PostGIS, геологические расчёты, карты, импорт Excel и отчёты. Не следует использовать эту оболочку как замену GeoReport для производственных расчётов.

## Принцип миграции

1. Сохранить GeoReport как контрольную рабочую версию.
2. Зафиксировать эталонные входные книги и результаты.
3. Выделить доменную модель и прикладные сценарии без изменения расчётных правил.
4. Переносить функции небольшими этапами и сравнивать результаты с GeoReport.
5. Подключать хранилище и графический интерфейс после появления стабильных контрактов данных.

См. также `ARCHITECTURE_MIGRATION.md` в корне репозитория.
